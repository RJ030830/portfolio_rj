Doce Algodão Ateliê

Site criado

HTML, CSS, JavaScript

Ver o site

Nesse projeto a ideia principal era criar um espaço online para exibir os produtos do ateliê e facilitar o contato com os clientes. O objetivo sempre foi oferecer praticidade para os clientes e conquistar um ganho de tempo precioso para a dona do ateliê. O catálogo digital utiliza um sistema de back-end simples para gerenciar e distribuir os produtos, um sistema de carrinho que organiza as escolhas e direciona o cliente a conversar com a vendedora já com seus modelos escolhidos.
